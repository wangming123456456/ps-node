# PS 节点插件 · 安装说明（新手版）

照这份说明做完，你会得到两样东西：

- Photoshop 里多一个 **「PS 节点」面板**
- 画布里多一个 **「Photoshop」节点**，能把画面推进 PS、也能把 PS 改完的画面拉回来

整个过程 3 步，**只有第 1 步要敲命令**，其余都是点鼠标。传图走的是本机内部的 127.0.0.1，不上传任何东西；画布侧不需要装任何插件。

---

## 0. 装之前，先确认这四件事

| 需要 | 怎么确认 | 不满足怎么办 |
|---|---|---|
| Photoshop **2024 或更新** | PS 菜单 → 帮助 → 关于 Photoshop，看版本号 ≥ 24.4 | 版本太低装不上这种插件，先升级 PS |
| 能正常打开画布 | 双击桌面上的 **「AIGC创作」** 图标（安装版自带中继）；网页版/开发版则双击「AIGC创作 网页版」快捷方式 | 画布都打不开就先别装插件，回头再弄 |
| 有 **Node.js 20+** | 命令行敲 `node -v`，能打印版本号就行 | 去 nodejs.org 下 LTS 版，一路下一步 |
| 能拿到 `ps-node` 这个项目文件夹 | 有 Git：`git clone https://github.com/wangming123456456/ps-node.git` | 没 Git 就让同事把整个文件夹打包发给你 |

第 1 步要往 `C:\Program Files` 里写文件，**所以 PowerShell 必须用管理员身份打开**（开始菜单搜 `PowerShell` → 右键 → 以管理员身份运行）。

---

## 第 1 步：装 Photoshop 里的面板

### 1.1 下载项目

在任意目录（比如 `D:\`）打开命令行：

```powershell
git clone https://github.com/wangming123456456/ps-node.git
```

没有 Git 的话，把别人给你的 `ps-node` 文件夹放到 `D:\ps-node` 也行，后面路径跟着改。

### 1.2 用管理员 PowerShell 跑安装脚本

```powershell
cd D:\ps-node
powershell -NoProfile -ExecutionPolicy Bypass -File scripts\install-uxp.ps1
```

成功的话会打印三行 `[ok]`：

```
[ok] UXP developer mode enabled: C:\Program Files\Common Files\Adobe\UXP\Developer\settings.json
[ok] PS plugin copied to: C:\Users\<你>\AppData\Roaming\Adobe\UXP\Plugins\External\a1b2c3d4_PS
[ok] Created PS.json directory (forces the External plugin fallback)
```

如果最后出现黄色警告 `Could not create ...`，说明没拿到管理员权限——用管理员重新开一次 PowerShell 再跑。

这个脚本实际上只做了三件事，知道一下后面好排查：

1. **打开 UXP 开发者模式**：写 `C:\Program Files\Common Files\Adobe\UXP\Developer\settings.json`，内容 `{ "developer": true }`。
2. **拷贝插件本体**：把 `ps-node\ps-uxp\` 复制到 `%APPDATA%\Adobe\UXP\Plugins\External\a1b2c3d4_PS`。
3. **防止插件"装完又被忘记"**：把 `%APPDATA%\Adobe\UXP\PluginsInfo\v1\PS.json` 换成一个**同名文件夹**。这一步看起来奇怪，但必须做——那个文件一旦存在，PS 就不再扫描 External 目录，而且它自己会把这个文件写成空列表 `{"plugins":[]}`，表现就是"第一次能用，重启 PS 插件就消失"。

> 不想跑脚本？也可以用管理员 PowerShell 手动三步：
>
> ```powershell
> # 1) 开发者模式
> New-Item -ItemType Directory -Force "C:\Program Files\Common Files\Adobe\UXP\Developer" | Out-Null
> Set-Content "C:\Program Files\Common Files\Adobe\UXP\Developer\settings.json" '{ "developer": true }'
> # 2) 拷插件
> $dest = "$env:APPDATA\Adobe\UXP\Plugins\External\a1b2c3d4_PS"
> New-Item -ItemType Directory -Force $dest | Out-Null
> Copy-Item D:\ps-node\ps-uxp\* $dest -Recurse -Force
> # 3) 让 PS 每次都去扫 External 目录
> #    如果这个 PS.json 里已经登记了别的 UXP 插件，先把它改名备份，别直接删
> Remove-Item "$env:APPDATA\Adobe\UXP\PluginsInfo\v1\PS.json" -Force -ErrorAction SilentlyContinue
> New-Item -ItemType Directory "$env:APPDATA\Adobe\UXP\PluginsInfo\v1\PS.json" -ErrorAction SilentlyContinue | Out-Null
> ```

### 1.3 完全退出 Photoshop，再打开

注意是**退出程序**（关掉所有文档、任务栏和托盘都不要留），不是只关文档。

### 1.4 打开面板

PS 菜单 → **增效工具（Plugins）→ PS 节点**。

> **第一次必须手动打开一次**：这个插件只有在面板被打开时才会启动脚本、才会去连中继。之后 PS 会记住它。

面板出来了，第一步就算成功。此时里面显示「中继未连接」是**正常的**，第 3 步会解决。

## 关于画布侧：不用装插件

> **v0.3 起 PS 能力已内置到图片卡片**：画布上任意一张图片卡片的工具条里都有「推送到 PS / 从 PS 取回」，选中卡片 PS 面板就会显示它。这一步可以直接跳过。
>
> - 如果之前装过旧插件：去「节点插件 → 第三方插件」把 `PS 节点` **卸载**（不卸载也能用，只是旧节点会多出一排按钮）。
> - 旧画布里的 Photoshop 节点会在打开画布时自动变成图片卡片，「目标文档 / 输出尺寸」挪到了「配置 → PS 节点」。
>
> 下面这段留着，只对没升级到 v0.3 的画布有效。

### （旧画布才需要）装画布里的插件

> 只有画布还停在 v0.3 之前才需要这一步。新画布直接跳过。

1. 打开画布页面。
2. 右上角一排小图标里，点最左边那个**拼图图标**（鼠标停上去提示「节点插件」）。
3. 切到 **「第三方插件」** 这一页，粘 `https://cdn.jsdelivr.net/gh/wangming123456456/ps-node@v0.2.0/dist/ps.js`，点「安装」。

## 第 2 步：让两边连上

中间那个"邮差"叫**中继**，地址 `127.0.0.1:23310`。**不用你手动开**：

- **安装版（桌面版）**：双击「AIGC创作」图标时自带中继，不需要任何额外操作。
- **网页版 / 开发版**：「AIGC创作 网页版」快捷方式会顺带拉起 `canvas-agent`，由它托管中继并把地址、token 注入页面。

你唯一要保证的是：**画布是从快捷方式/启动脚本打开的，而不是直接双击 `index.html`**（直接开 html 白屏，也没有 agent）。

怎么确认通了：

| 看哪里 | 正常 | 不正常 |
|---|---|---|
| 画布「配置 → PS 节点」→「中继」 | 显示 `http://127.0.0.1:23310` | 显示「未注入（canvas-agent 没在运行）」→ agent 没在跑 |
| PS 面板文档那一行（文档名右边） | 「中继已连接」 | 「中继未连接」→ 23310 没监听，或被别的程序占着 |
| 两边都对 | 图片卡片工具条点「从 PS 取回」能拿到 PS 画面 | — |

## 第 3 步：跑通第一次

1. 在画布上**选一张图片卡片**（新建或已有的都行）。PS 面板会自动显示这张图，底部状态行写「画布选中：xxx · 点画面落层」。
   PS 里还没打开文档的话先新建/打开一个，落层需要目标文档。
2. **在 PS 里精修**（或直接画），改完点面板顶部那排的 **「发送画布」** → 画面写回画布上选中的那张卡片。
3. 需要再用画布的 AI 能力改：选中这张卡，用工具条上的裁剪 / 消除 / 调色…（结果直接写回卡片），改完点 **「推送到 PS」** 送回去继续修。
4. 定稿了就**点一下 PS 面板里的画面** → 按 PS 当前选区落成图层。

到这里闭环就通了：**画布选图 → PS 里改 → 发送画布 → 画布 AI 再改 → 推送回 PS → 落层**，一直转到成品。

> PS 面板上的两个动作只有两个名字：**「落层」**（点画面）和 **「发送画布」**（按钮）。画布侧对应的是工具条上的 **「推送到 PS」** 和 **「从 PS 取回」**，后者和「发送画布」是同一个动作。

## 常见问题

| 现象 | 原因 | 怎么处理 |
|---|---|---|
| PS 的「增效工具」里没有「PS 节点」 | 没开开发者模式 / PS 版本太低 / 没重启 PS / 目录名不对 | 重跑 `install-uxp.ps1`；确认 `...\UXP\Plugins\External\a1b2c3d4_PS\manifest.json` 存在；彻底重启 PS |
| 第一次能用，重启 PS 后插件又没了 | `PluginsInfo\v1\PS.json` 又变回文件了 | 重跑 `install-uxp.ps1`（它会把文件换成目录） |
| PS 面板一直「中继未连接」 | 23310 没在监听，或端口被占 | `netstat -ano \| findstr 23310` 看有没有 LISTENING；没有就重开画布页/重启 agent；有但是别的程序就杀掉它 |
| 配置 → PS 节点里「中继」显示未注入 | 画布不是从快捷方式打开的，或 `canvas-agent` 没在跑 | 重开一次画布（安装版双击「AIGC创作」；网页版用「AIGC创作 网页版」）；仍不行就重启电脑上的画布智能体托盘 |
| 点生成报「AI 配置未就绪」 | 没填模型 / Key | 右上角齿轮（配置）→ 渠道 → 填 Base URL + API Key，选一个生图模型 |
| 点了 PS 面板里的预览，图层没多出来 | 落层失败 | PS 面板「设置 → 日志」看 `点击结果预览 / 开始落层 / 具体错误`；日志也在 PS 的 localStorage `ps-node:log` |
| PS 面板预览区全黑 / 写着「解不出来」 | 这张图的格式 PS 侧不支持 | 换 PNG/JPEG 再试；1024 以内的图会原样透传，不需要压缩 |
| 点「推送到 PS」报「中继未就绪」 | 画布不是从快捷方式/宿主打开的 | 重开画布，确认配置里中继显示 `127.0.0.1:23310` |

## 更新 / 卸载

**更新**：PS 面板改过之后，重跑一次 `scripts\install-uxp.ps1`，然后在 PS 里关掉面板再打开（或重启 PS）。画布侧不用动，它跟着画布版本走。

**卸载**：删掉 `%APPDATA%\Adobe\UXP\Plugins\External\a1b2c3d4_PS` 整个文件夹，重启 PS。

删除后 UXP 开发者模式的开关可以留着，不影响别的。

## 附：东西都在哪

| 东西 | 位置 |
|---|---|
| PS 面板插件本体 | `%APPDATA%\Adobe\UXP\Plugins\External\a1b2c3d4_PS\` |
| UXP 开发者模式开关 | `C:\Program Files\Common Files\Adobe\UXP\Developer\settings.json` |
| PS 的 UXP 插件登记表 | `%APPDATA%\Adobe\UXP\PluginsInfo\v1\PS.json` ← **必须是文件夹，不能是文件** |
| 画布侧设置（取回尺寸等） | 浏览器本地，画布「配置 → PS 节点」里改 |
| 本地 agent 配置（含中继 token） | `%USERPROFILE%\.infinite-canvas\canvas-agent.json` |
| 中继日志 | `%USERPROFILE%\.infinite-canvas\logs\ps-relay.log` |
