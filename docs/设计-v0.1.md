# PS 节点 · 技术设计

> 状态：草案 v0.1（2026-11-07）
> 上游文档：`规划.md`（目标、里程碑、排期）
> 一句话：**画布上放一个节点，把图推进 Photoshop，人在 PS 里改，一键 AI 优化后贴回 PS 新图层并同步回画布。**

---

## 1. 约束从哪来

设计前先把三件事钉死，后面所有取舍都由它们推出来：

| 事实 | 来源 | 推论 |
|---|---|---|
| 画布插件是**浏览器里的 ESM** | `aigc-comfyui-plugin/src/index.tsx`，`definePlugin` + React 组件 | 只能发 HTTP，碰不到本机进程、读不了文件 |
| Photoshop **不提供 HTTP 端口** | Adobe 官方 | 浏览器 ↔ PS 之间必须有本地进程转接 |
| ComfyUI 见 `Origin` 头直接 403 | 作者 README 里明说，所以有 `canvas-proxy` | 浏览器直连 ComfyUI 不可靠，交给桥代理最省事 |
| 宿主 SDK 未公开 | 同仓库 build.mjs 注释 | 本地构建要 `CANVAS_SDK`；API 只能按 `comfyui.js` 反推 |

### 方案对比

| 方案 | 可行性 | 代价 | 结论 |
|---|---|---|---|
| A. 浏览器直连 PS | 不可能 | — | 否 |
| B. 写 UXP 插件（.ccx），PS 里发请求给画布 | 可行 | 要签名/装插件；方向相反（PS 发起）；画布得开端口 | 否（v1） |
| C. 本地桥 + COM 驱动 PS | 可行 | 只能 Windows；要跑一个后台进程 | **采用** |
| D. 桥 + UXP 插件双端 | 可行 | 两套代码、两处安装 | 留作 M5 增强（图层级控制） |

### ADR（架构决策记录）

| 编号 | 决策 | 理由 | 代价 |
|---|---|---|---|
| ADR-1 | 用 **COM**（`Photoshop.Application`）而不是 UXP | 免签名、免装插件、`DoJavaScript` 能跑任意 ExtendScript，等于 UXP 的能力全集 | 仅 Windows |
| ADR-2 | 桥用 **PowerShell 单文件** | 零依赖、双击即跑、好分发；COM 原生支持；`TcpListener` 已验证可用 | 单线程、代码偏长 |
| ADR-3 | 桥**顺带代理 ComfyUI** | 一个地址解决 CORS + 403；插件里不用再配 proxy | 桥多 60 行 |
| ADR-4 | **插件编排 optimize**（桥只给原子操作） | `comfy.ts` 里已有可抄的 TS 实现；桥保持薄，好维护 | 大图往返浏览器（用 `maxEdge` 兜） |
| ADR-5 | 插件**复用** comfyui 插件的 `library.v1` | 用户已经导过工作流，不必再导一遍 | 两插件版本耦合，只读不写即可 |

## 2. 总体架构

```
┌────────────────────── 浏览器（画布页面）──────────────────────┐
│ ps.js                                                        │
│  ├─ src/index.tsx   definePlugin，声明 ps:layer 节点           │
│  ├─ src/bridge.ts   桥客户端（health/docs/push/pull）+ 端口探测 │
│  ├─ src/comfy.ts    ComfyUI 执行（经桥代理）— 移植自 comfyui 插件│
│  └─ src/ui.tsx      Content / Panel / toolbar                 │
└─────────────────────────────┬────────────────────────────────┘
                              │ HTTP 127.0.0.1:2311x，CORS(*)+Token
┌─────────────────────────────▼────────────────────────────────┐
│ ps-bridge.ps1（常驻，控制台窗口，带日志）                        │
│  ├─ HTTP 层   TcpListener + 手写请求解析 + 响应 + CORS + 鉴权    │
│  ├─ /ps/*     COM → DoJavaScript(ExtendScript) → JSON          │
│  ├─ /comfy/*  反向代理（剥 Origin/Referer，透传 body）           │
│  └─ mock     无 PS 时用 System.Drawing 生成占位图                │
└──────┬──────────────────────────────────────┬─────────────────┘
       │ COM (IDispatch)                      │ HTTP
┌──────▼────────┐                      ┌──────▼────────┐
│  Photoshop    │                      │  ComfyUI 8188 │
└───────────────┘                      └───────────────┘
```

**进程与端口**

| 进程 | 端口 | 启动者 | 生命周期 |
|---|---|---|---|
| 画布（浏览器） | — | 用户 | 页面开着就在 |
| `ps-bridge.ps1` | 23110（占用则 23111…23119） | 用户双击 `start.cmd` | 常驻，关窗口即退 |
| ComfyUI | 8188 | 用户 | 常驻 |
| Photoshop | — | 桥遇到时自动 `New-Object -ComObject` | PS 没开也能拉起（COM 会启动它） |

**运行环境要求**

- Windows 10/11 x64；**Windows PowerShell 5.1 即可**，不要求 PowerShell 7（脚本里不用 7.x 专有语法）。
- `.ps1` 一律存成 **UTF-8 带 BOM**：5.1 默认按 ANSI(GBK) 读文件，没 BOM 的中文直接解析失败。
- 数据目录默认 `%LOCALAPPDATA%\ps-bridge`，用 `-DataDir` 可覆盖（换盘 / 受限环境 / 测试）。
- 桥只绑 `127.0.0.1`，**浏览器必须与桥同机**；跨机需改绑 `0.0.0.0` + token + 防火墙（M5）。
- 开发和运行分机进行：本机只用 mock 验证，真 PS/ComfyUI 在目标机（见 `规划.md` §8）。

**目录（运行时）**

```
%LOCALAPPDATA%\ps-bridge\
  config.json      # 端口、token、comfy 地址、maxEdge
  token.txt        # 首次启动生成，32 hex
  bridge.log       # 追加写，10MB 轮转
  tmp\             # 每次请求一个子目录，退出时清空
```

## 3. 桥设计

### 3.1 启动与自愈

```powershell
param([int]$Port = 23110, [string]$Comfy = "http://127.0.0.1:8188", [switch]$Mock, [switch]$NoToken)
```

1. 读 `config.json`，命令行参数覆盖。
2. 从 `$Port` 起依次试绑，绑上就把实际端口写进 `config.json` 和标题栏（`PS Bridge · 23110 · mock`）。
3. 探测 PS：`[type]::GetTypeFromProgID("Photoshop.Application")` 为 `$null` → 置 `mock = $true`，日志警告，**不退出**。
4. 循环 `AcceptTcpClient()`；每个连接设 `ReceiveTimeout=30000`，处理完 `Connection: close`。

### 3.2 HTTP 层

- 只支持 HTTP/1.1，忽略 keep-alive（响应头带 `Connection: close`）。
- 读请求直到 `\r\n\r\n`，按 `Content-Length` 读足 body。
- 路由表：`method + path 前缀` → handler。
- 响应统一 `Content-Type: application/json; charset=utf-8`，图片端点返回原始 PNG 字节。
- CORS：所有响应加

```
Access-Control-Allow-Origin: *
Access-Control-Allow-Headers: content-type, x-bridge-token
Access-Control-Allow-Methods: GET, POST, OPTIONS
```

- `OPTIONS` 一律 204。
- **鉴权**：除 `GET /health` 外，要求 `X-Bridge-Token` 匹配 `token.txt`；不匹配 401。`-NoToken` 关闭（仅本机调试）。

### 3.3 错误约定

```json
{ "ok": false, "error": { "code": "PS_NOT_RUNNING", "message": "Photoshop 没有响应", "hint": "先手动打开 Photoshop 再试" } }
```

| code | HTTP | 含义 | hint |
|---|---|---|---|
| `BAD_REQUEST` | 400 | 参数缺失/JSON 坏 | — |
| `UNAUTHORIZED` | 401 | token 不对 | 去 `config.json` 抄 token |
| `TOO_LARGE` | 413 | 图片超过 32MB | 调小 `maxEdge` |
| `DOC_NOT_FOUND` | 404 | 指定文档不存在 | 下拉重选 |
| `PS_NOT_RUNNING` | 503 | COM 拿不到 | 打开 PS |
| `PS_BUSY` | 503 | 文档正在保存/有模态框 | 关掉对话框再试 |
| `SCRIPT_ERROR` | 500 | ExtendScript 抛错 | 带 `line` 和原始 message |
| `COMFY_DOWN` | 502 | 连不上 8188 | 启动 ComfyUI |
| `COMFY_TIMEOUT` | 504 | 超时（默认 600s） | 换小工作流 |

### 3.4 API 契约

所有图片字段统一 `data:image/png;base64,...`。

#### `GET /health`

```json
{ "ok": true, "bridge": "0.1.0", "port": 23110, "photoshop": false, "psVersion": "", "mock": true, "tokenRequired": true, "comfy": "http://127.0.0.1:8188" }
```

#### `GET /ps/docs`

```json
{ "ok": true, "docs": [ { "name": "未标题-1", "width": 2048, "height": 2048, "layers": ["背景", "AI 优化 1"] } ] }
```

#### `POST /ps/push`

```json
// 请求
{ "image": "data:image/png;base64,...", "mode": "layer", "doc": "未标题-1", "layerName": "AI 优化 10:02" }
// mode = "newDoc" 时忽略 doc，直接 app.open() 新开一个文档
// 响应
{ "ok": true, "doc": "未标题-1", "layer": "AI 优化 10:02", "width": 2048, "height": 2048 }
```

#### `POST /ps/pull`

```json
// 请求（doc 省略 = 当前文档；layer 省略 = 整幅拼合）
{ "doc": "未标题-1", "maxEdge": 2048 }
// 响应
{ "ok": true, "image": "data:image/png;base64,...", "doc": "未标题-1", "width": 2048, "height": 2048 }
```

#### `ANY /comfy/*`

透传到 `{comfy}/{path}`，方法/body/content-type 原样，响应状态与字节原样返回。

### 3.5 PS 驱动层

```powershell
function Get-PsApp {
    if ($script:psApp) { return $script:psApp }
    $script:psApp = New-Object -ComObject Photoshop.Application
}
function Invoke-Js([string]$Code) {
    $app = Get-PsApp
    try { return $app.DoJavaScript($Code, $null, 1) }
    catch { return $app.DoJavaScript($Code, @(), 1) }   # 个别版本不接受 $null
}
```

拼脚本的两个工具函数（**所有外部字符串必须过这里**）：

```powershell
function JsStr([string]$s)  { '"' + ($s -replace '\\','\\\\' -replace '"','\"' -replace "`r",'' -replace "`n",'\n') + '"' }
function JsPath([string]$p) { JsStr ($p -replace '\\','/') }   # ExtendScript 认正斜杠
```

#### push

```js
// doc 为空 → 新文档
app.open(new File("C:/.../in.png"));
JSON.stringify({ name: app.activeDocument.name, width: app.activeDocument.width, height: app.activeDocument.height });

// doc 有值 → 贴成智能对象图层
var doc = null;
for (var i = 0; i < app.documents.length; i++) if (app.documents[i].name === "未标题-1") doc = app.documents[i];
if (!doc) throw new Error("文档不存在：未标题-1");
app.activeDocument = doc;
var layer = doc.place(new File("C:/.../in.png"));
layer.name = "AI 优化 10:02";
JSON.stringify({ name: doc.name, layer: layer.name, width: doc.width, height: doc.height });
```

#### pull

```js
var doc = null;
for (var i = 0; i < app.documents.length; i++) if (app.documents[i].name === "未标题-1") doc = app.documents[i];
if (!doc) throw new Error("文档不存在");
var f = new File("C:/.../out.png");
var opt = new PNGSaveOptions(); opt.compression = 6;
doc.saveAs(f, opt, true, Extension.LOWERCASE);   // asCopy = true，不动原文档、不弄脏存盘状态
```

拼接图层时先 `doc.duplicate()` 再 `flatten()`，导出完 `close(SaveOptions.DONOTSAVECHANGES)`，避免污染用户文档。
`maxEdge` 用 `doc.resizeImage()` 在**副本**上做。

#### docs

```js
var out = [];
for (var i = 0; i < app.documents.length; i++) {
  var d = app.documents[i], ls = [];
  for (var j = 0; j < d.layers.length; j++) ls.push(d.layers[j].name);
  out.push({ name: d.name, width: d.width, height: d.height, layers: ls });
}
JSON.stringify(out);
```

### 3.6 ComfyUI 代理

- `$req.Path` 以 `/comfy` 开头 → 目标 `$Comfy + ($path -replace '^/comfy','')`。
- **剥掉** `Origin`、`Referer`（这是 403 的根因）。
- `Invoke-WebRequest -SkipHttpErrorCheck`，原样回传状态码、`Content-Type`、`Content-Length`、字节。
- 超时 600s（工作流跑得久）。

### 3.7 mock 模式

PS 不可用时（或 `-Mock`）：

| 端点 | 行为 |
|---|---|
| `/ps/docs` | 固定返回 `[{name:"mock.psd"}]` |
| `/ps/push` | 把图写到 `tmp\mock\doc.png`，返回成功 |
| `/ps/pull` | 有 `doc.png` 就回它，否则 `System.Drawing` 画一张 1024×1024 渐变+时间戳 |
| `/comfy/*` | 照常代理（真 ComfyUI 仍可跑） |

目的：**没有 PS 也能把画布侧 UI 和链路验完**（M0 验收靠它）。

### 3.8 临时文件

```
tmp\<requestId>\
  in.png      推送的图
  out.png     导出的图
```
- `requestId = [guid]::NewGuid().ToString('N')`。
- 处理完立即删目录；启动时清空 `tmp\`；退出 `finally` 再清一次。

### 3.9 代码结构（单文件内分区）

```
ps-bridge.ps1
  #region 配置与日志      Read-Config / Write-Config / Write-Log
  #region HTTP 骨架        Start-Bridge / Receive-Request / Send-Response

  #region PS 驱动          Get-PsApp / Invoke-Js / Invoke-PsPush / Invoke-PsPull / Get-PsDocs
  #region Comfy 代理       Invoke-ComfyProxy
  #region mock             New-MockImage
```

### 4.2 节点声明

```ts
export default definePlugin({
  id: "ps",
  name: "PS 节点",
  version: "0.1.0",
  nodes: [{
    type: "ps:layer",
    title: "Photoshop",
    icon: "🎨",
    description: "把图推进 Photoshop，改完再拿回来",
    defaultSize: { width: 360, height: 360 },

```

### 4.3 metadata 契约

| 键 | 类型 | 说明 |
|---|---|---|
| `content` | dataURL | 节点当前图（下游 `resource` 取这个） |
| `psStatus` | `idle\|pushing\|inPS\|pulling\|optimizing\|done\|error` | 状态机 |
| `psDoc` | string | 绑定的 PS 文档名 |
| `psLayer` | string | 最后一次写入的图层名 |
| `psError` | string | 失败原因（悬停显示全文） |
| `psStartedAt` | number | 用于算耗时（`运行中 12s`） |
| `psSettingsOpen` | boolean | 参数卡展开态；**必须存 metadata**，画布缩放会重建组件 |

节点级配置存 `ctx.storage`，键 `node:<nodeId>`：`{ mode, doc, layerName, maxEdge, workflowId, prompt, negative }`。
桥连接信息存**共享**键 `settings.ps.v1`：`{ baseUrl, token }`。

### 4.4 状态机

```
idle ──push──▶ pushing ──ok──▶ inPS ──optimize──▶ optimizing ──ok──▶ done
  ▲               │                │                                  │
  └──── error ◀───┴────────────────┴────────── error ◀───────────────┘
inPS ──pull──▶ pulling ──ok──▶ done
```
- 每个 `*ing` 态写 `psStartedAt`，Content 每秒刷耗时。
- `done` 不会自动回 `idle`，下次动作直接覆盖。
- 任一失败保留 `content` 原图，只置 `psError`。

### 4.6 三个动作的调用序列

```ts
// ① 推送到 PS
const url = await toDataUrl(imageSourceOf(ctx.node));      // blob: → dataURL（画布恢复后常是 blob）
await bridge.push({ image: url, mode, doc, layerName });
ctx.updateMetadata({ psStatus: "inPS", psDoc: doc, psError: "" });

// ② 从 PS 取回
const { image, doc } = await bridge.pull({ doc, maxEdge });
ctx.updateMetadata({ content: image, psStatus: "done", psDoc: doc });

// ③ AI 优化回 PS（ADR-4：插件编排）
const { image } = await bridge.pull({ doc, maxEdge });        // a. 从 PS 拿当前画面
const result   = await comfy.run({ workflow, prompt, negative, image });  // b. 经桥代理跑工作流
await bridge.push({ image: result, mode: "layer", doc, layerName: `AI 优化 ${hh:mm}` }); // c. 贴回
ctx.updateMetadata({ content: result, psStatus: "done", psLayer });
```

### 4.7 端口与连接

```ts
async function findBridge(): Promise<string> {
  for (let port = 23110; port <= 23119; port++) {
    const url = `http://127.0.0.1:${port}`;
    try { const r = await fetch(`${url}/health`, { cache: "no-store" }); if (r.ok) return url; } catch {}
  }
  throw new Error("没找到桥：先运行 start.cmd");
}
```

- 所有请求带 `X-Bridge-Token`；401 时提示「去桥窗口抄 token」。

## 6. 测试计划

### M0（无 PS）

1. `start.cmd -Mock` → 控制台打印端口和 token。
2. `curl http://127.0.0.1:23110/health` → `mock:true`。
3. 画布上建节点 → 面板自动连上（绿点）。
4. 推一张图 → 再取回 → 节点图变化且状态流转正确。
5. 故意停桥 → 点推送 → 出现「没找到桥」错误文案，不崩。

### M1–M3（有 PS）

| 用例 | 期望 |
|---|---|
| 空 PS 时点推送（newDoc） | PS 被 COM 拉起，出现新文档 |
| 已有文档点推送（layer） | 出现智能对象图层，名字对 |
| 文档名不存在 | 404 + 中文提示，不弹 PS 报错框 |
| PS 里有未保存对话框 | 503 `PS_BUSY` + 提示关对话框 |
| 拉取整幅 | 图与 PS 里一致（肉眼比对） |
| 拉取时 PS 文档是 CMYK/16bit | 仍导出 PNG（必要时先转 sRGB） |
| 关掉 ComfyUI 跑 AI | 502 + 明确文案 |
