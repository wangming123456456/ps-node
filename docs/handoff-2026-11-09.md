# 交接：PS 节点插件（ps-node）

2026-11-09 晚。`main` 已提交（`f6c9cf0`）、未 push；工作区干净。完整链路背景见画布仓库 `docs/superpowers/handoff/2026-11-09-ps-node-loop-handoff.md`，这里只记插件侧。

## 现状

- `canvas-plugin/`：中继地址/token 只读宿主注入（本地只存目标文档、输出尺寸）；双击不再弹设置；监听 `metadata.generatedAt`，把画布生成结果发 `preview` 命令给 PS 面板。`dist/ps.js`（24969 B）已构建并同步进画布市场的插件缓存。
- `ps-uxp/`：面板新增 `preview` 命令——只把图放进「结果」预览、切到结果视图，不落层；结果预览上盖透明点击层 `#preview-hit`，点画面才 `applyRender()` 落层；底部按钮条已去掉；落层流程有日志（点击/开始/跳过原因）。
- `scripts/`：`install-uxp.ps1`（部署面板 + 处理 UXP 插件表）、`sync-canvas-plugin-cache.mjs`（构建后同步画布插件缓存）。

## 必须知道的坑

1. **改完 `ps-uxp/` 要重开面板或重启 PS**（UXP 只在面板启动时跑脚本）。
2. **重启丢插件**：`%APPDATA%\Adobe\UXP\PluginsInfo\v1\PS.json` 存在就不扫 External，且 PS 会把它写成空表。现在已换成**同名目录**；`install-uxp.ps1` 自动处理，别换回文件。
3. **`install-uxp.ps1` 必须纯 ASCII**：`powershell -File` 走 5.1，UTF-8 无 BOM 的中文会按 ANSI 解码导致语法错。
4. **画布只读插件市场缓存**：`npm run build` 后在仓库根跑 `node scripts\sync-canvas-plugin-cache.mjs`，再刷新画布页；只换 `dist/ps.js` 不生效。
5. **中继 health 的 `photoshop.connected` 是 15s 窗口**，面板 25s 长轮询，会间歇误报未连接；不要拿它当发命令的前置判断（插件已去掉）。
