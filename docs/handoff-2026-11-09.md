## 必须知道的坑

1. 改完 `ps-uxp/` 必须关掉再打开面板或重启 PS（UXP 只在面板启动时跑脚本）。
2. `%APPDATA%\Adobe\UXP\PluginsInfo\v1\PS.json` 一旦存在，PS 就不扫 External，且 PS 会把它写成空表 → 重启一次插件就消失。现在已换成**同名目录**；`install-uxp.ps1` 会自动处理，别把它删掉换成文件。
3. `install-uxp.ps1` 必须保持纯 ASCII（Windows PowerShell 5.1 按 ANSI 读 UTF-8，中文会让脚本语法错）。
4. 画布插件产物更新后，只重装 dist 不够：画布读的是插件市场缓存，需要 `node scripts/sync-canvas-plugin-cache.mjs`（读 agent 配置里的 `canvasRoot`，自动备份）改 `.state` 里的插件源码，再刷新画布页。
5. 中继 health 的 `photoshop.connected` 是 15s 窗口、面板 25s 长轮询，会间歇误报未连接；不要再拿它当发命令的前置判断。
